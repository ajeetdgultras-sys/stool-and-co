# Stool & Co

Responsive product homepage recreated from the supplied design. Serve `dist/` with any static web host; no build step is required.

Original product images and embedded font subsets are stored locally in `dist/assets/`.

The website is also published privately with ChatGPT Sites. GitHub stores a source copy; pushes here do not automatically deploy to Sites.

Before the customer campaign launches, replace the generic Kickstarter links and add the confirmed enquiry email.
